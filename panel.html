1. Conectar con GitHub

¿Cómo consigo el token?
  1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nombre: nfc-panel.
  3. En Repository access elige Only select repositories y marca solo nfc-data.
  4. En Permissions → Repository permissions → Contents elige Read and write.
  5. Pulsa Generate token, cópialo y pégalo arriba.
Este token solo se guarda en tu dispositivo. Los juegos se suben a tu repo privado, no a la página pública.
